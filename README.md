##  Sobre o Projeto
Muitos iniciantes desistem por não saber por onde começar ou por se perderem no mar de conteúdos. O **DevPro** resolve isso através de uma interface minimalista, onde o aluno tem um roteiro guiado e o controle total do seu progresso.

---

##  Tecnologias
O projeto foi construído com o que há de mais moderno no mercado:

*   **Framework**: Next.js 16 (App Router)
*   **Linguagem**: TypeScript
*   **Estilização**: Tailwind CSS
*   **Integração**: Discord API (Status de comunidades em tempo real) Youtube API (Melhores conteúdos gratuitos da internet)
*   **Persistência**: LocalStorage (Progresso salvo no navegador)

---

##  Funcionalidades

> **Filtragem de Conteúdo de Alta Performance**
> Não entregamos apenas uma lista. Realizamos uma curadoria rigorosa, selecionando conteúdos que prezam pela didática clara, projetos práticos e profundidade técnica, garantindo uma base sólida para quem está entrando na área.

*   **Roadmap Guiado**: Roteiro estruturado do básico ao avançado.
*   **Progresso Automático**: Sistema inteligente que salva onde você parou.
*   **Hub de Comunidades**: Visualize comunidades de devs com dados em tempo real.
*   **Favoritos**: Tenha um histórico centralizado dos seus cursos.

---

## 💡 Ajude-nos a Evoluir
O **DevPro** é um projeto vivo e feito para a comunidade. Se você encontrou algum bug, teve alguma dificuldade ou tem uma ideia de funcionalidade que gostaria de ver na plataforma, não guarde para você!

Utilize o nosso **[sistema de feedback integrado](https://dev-pro-psi.vercel.app/meu-progresso)**, disponível na própria plataforma, para nos enviar a sua sugestão. A sua opinião é fundamental para tornarmos o DevPro o melhor lugar para aprender a programar.
